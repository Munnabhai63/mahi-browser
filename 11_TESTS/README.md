# 11_TESTS — Automated Test Suites

This folder contains all automated tests categorized by test type.

## Directory Structure
- unit/: Fast isolated unit tests (encryption, validation, services, licensing)
- integration/: Multi-module integration tests (proxies, sync, importer, etc.)
- stress/: Multi-cycle stress & stability tests (10-cycle, 20-cycle loops)
- e2e/: Real browser automation & Playwright E2E verification tests
