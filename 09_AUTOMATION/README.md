# 09_AUTOMATION — RPA Workflows, Synchronizer & Warmup

This folder contains the Playwright RPA automation engine, multi-window mouse/keyboard action synchronizer, autonomous profile warmer, and captcha solvers.

## Directory Structure
- automation-engine.ts: Step-based RPA workflow runner
- sync-hub.ts: Multi-profile live event mirroring hub
- cdp-synchronizer.ts: CDP raw WebSocket input broadcaster
- cookie-warmer-service.ts: Autonomous background cookie warmer
- captcha-service.ts: 2Captcha, CapMonster, AntiCaptcha solvers
