# 03_HARDWARE — Hardware, System & Network Operations

This folder contains hardware fingerprinting, ADB mobile proxy rotation, system telemetry, diagnostics, and desktop distribution helpers.

## Directory Structure
- device-id.ts: Privacy-preserving hardware device ID generation
- mobile-rotator-service.ts: Android ADB 4G/5G mobile proxy rotator & IP check
- resource-monitor-service.ts: CPU/RAM usage telemetry & memory optimizer
- diagnostics-service.ts: Anti-bot fingerprint audit & 1-click auto-repair
- distribution-service.ts: Local network IP sharing & Windows shortcut repair
