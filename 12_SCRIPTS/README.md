# 12_SCRIPTS — Build, Dev & Utility Scripts

This folder contains development shortcuts, batch launchers, installer builders, and post-build utility scripts.

## Directory Structure
- start-app.bat: Quick 1-click application launcher
- Start-Web-Admin.bat: Launches Web Admin portal in default browser
- Start-Super-Admin.bat: Launches Secret Super Admin console
- Fix-Desktop-Shortcuts.bat: 1-click Windows desktop icon repair
- Build-Installers.bat: Builds Setup & Portable .exe packages
- create-desktop-shortcut.ps1: PowerShell shortcut & icon cache script
- fix-preload.cjs: Post-build script copying CommonJS preload
